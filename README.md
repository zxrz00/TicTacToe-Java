# TicTacToe-Java
This is a Tic-Tac-Toe GUI written in Java
Reference: https://github.com/MitchellAW/Tic-Tac-Toe/tree/master

STEP 1: List down all the Java program

$ ls
Boardz.java  Opponent.java  TTTGUI.java

STEP 2: Compile all Java code           

$ javac Boardz.java Opponent.java TTTGUI.java

STEP 3: List down all the Java compiled code

$ ls
 Boardz.class   Opponent.class  'TTTGUI$myActionListener.class'   TTTGUI.java
 Boardz.java    Opponent.java    TTTGUI.class

STEP 4: Run the GUI

$ java TTTGUI
